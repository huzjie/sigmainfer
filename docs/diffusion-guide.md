# 分块扩散原理（怎么实现的）

## 自回归的瓶颈

自回归 `p(t_i | t_<i)` 每一步只生成一个 token，序列长度 N 需要 N 次串行前向，无法并行，
且前面 token 的错误会向后续级联。

## 分块扩散的核心思想

把生成序列切成 block。每个 block 内：

1. 所有位置初始化为 [MASK]。
2. 模型对整条序列（前缀 + 掩码块）做一次前向，得到每个掩码位置的词表分布。
3. 按掩码调度决定「这一步揭开多少」，按置信度门槛决定「揭开哪几个」。
4. 重复 2~3，直到块内全部 unmask（或步数耗尽强制收尾）。
5. 该块作为前缀，进入下一块。

因为第 2 步一次前向就对块内所有位置打分，块内并行度 = block_size，吞吐显著高于自回归。

## 关键超参

| 参数 | 含义 | 影响 |
| --- | --- | --- |
| `block_size` | 每块 token 数 | 大=高并行，小=高质量 |
| `num_steps` | 每块去噪步数 | 多=质量高，少=快 |
| `schedule` | 掩码调度曲线 | 决定「早期多揭还是均匀揭」 |
| `confidence_threshold` | 门槛 | 高=保守，低=激进 |

## 与图像扩散的关系

图像扩散在像素/潜空间逐步去噪；文本扩散在离散 token 空间逐步「揭开掩码」。两者共享
「逐步 refine」的思想，但文本是离散的，所以用「掩码 + 置信度」代替连续噪声调度。
