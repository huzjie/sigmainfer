# 设计笔记

## 为什么用随机权重做参考实现

真实 3B/8B 权重无法随仓库分发，且纯 Python 加载不可行。随机缩小规模权重
（dim=64/2 层）让「分块扩散」整条链路在任何机器可跑通、可观测、可改参数，
把重心放在**调度与采样**这个真正的技术点上，而不是模型本体。

## 为什么采样器与调度器走注册表

分块扩散的工程价值集中在「怎么揭掩码」，而非模型。采样器/调度器可替换，
方便做消融实验（换 schedule 看吞吐变化、换 sampler 看质量变化）。

## 为什么早停 + 兜底并重

只做早停会卡死（某些位置一直低置信），只做固定步数会浪费（快的块也跑满）。
两者配合：早停省算力，兜底保下限。
