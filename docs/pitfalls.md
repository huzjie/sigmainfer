# 踩坑与解法

## 坑 1：块设太大，质量塌方

**现象**：block_size=256 时吞吐很高，但输出出现大量无意义 token。
**解法**：块内低置信位置被强行定死。先用 16/64 的块，配合多步去噪与门槛。

## 坑 2：一步 unmask 当扩散

**现象**：num_steps=1 时输出退化，等同并行贪心。
**解法**：多步去噪，配合 cosine schedule 逐步揭开。

## 坑 3：块卡死不出结果

**现象**：某块若干位置一直低置信，步数耗尽仍掩码，整条生成挂起。
**解法**：兜底收尾——步数耗尽后对剩余掩码 argmax 强制揭开。

## 坑 4：门槛退到 0

**现象**：连续停滞导致 threshold 一路衰减到接近 0，退化成无门槛。
**解法**：设 min_value 下限。

## 坑 5：基准对比有噪声

**现象**：自回归 vs 扩散的差距被实现差异淹没。
**解法**：同引擎、同权重、同 prompt、同 seed。
